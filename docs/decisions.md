# Decisions

Every choice that shaped se-forge, numbered. The code, the skills and the hooks' messages cite them as
"decision <n>"; [CHANGELOG.md](../CHANGELOG.md) says which version delivered each. Decisions 1-24 were made on
2026-10-06, before the kit was built; the later ones as each feature was asked for, tried and accepted.
